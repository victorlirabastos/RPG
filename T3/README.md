# T3 — Lost Map

**Disciplina:** Resolução de Problemas com Grafos, UNIFOR.
**Problema:** [Kattis Lost Map](https://open.kattis.com/problems/lostmap).
**Linguagem prevista:** Python.

O trabalho recupera as estradas originais de uma rede de vilas a partir de sua matriz de distâncias. A modelagem usa uma árvore geradora mínima (AGM) no grafo completo ponderado pelas distâncias.

O T3 segue a organização adotada no RPG como diretório autocontido. Se o requisito da disciplina for um repositório exclusivo para o T3, o uso do RPG compartilhado pode não atendê-lo.

## Uso de IA

O Codex auxiliou na conferência das fontes, na documentação, no protótipo de estudo e na comparação local das implementações. O grupo deve revisar os resultados e conseguir explicar e reproduzir a adaptação.

O enunciado docente consultado descreve três entregas independentes para a AP3. Este diretório documenta o Lost Map, da classe AGM, no escopo indicado para este trabalho.
